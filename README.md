Ответы на контрольные вопросы
1.IL это промежуточный язык, в который компилируется исходный код C#
2.Потому что NET сборки содержат метаданные и IL код 
3.В Debug генерируется больше IL инструкций в Release компилятор удаляет неиспользуемые переменные, встраивает короткие методы.
4.В режиме release компилятор и jit компилятор оптимизируются. В Debug код неоптимизированный.
5.Потому что любой человек может открыть dll  в текстовом редакторе и увидеть пароль.
